# Hostinger Website Builder Kod Arşivi

Bu klasör, https://kravmaga.com.tr üzerindeki Hostinger Website Builder sayfalarında kullanılan özel HTML/CSS bloklarının sürüm arşividir.

## Çalışma düzeni

- Canlı site Hostinger Website Builder üzerinde kalır.
- Bu klasördeki dosyalar otomatik deploy edilmez; güvenli yedek ve sürüm kaynağıdır.
- Onaylanmış son çalışan kodlar sayfa bazında burada tutulur.
- Tablet standardı: 751px–1100px aralığı için ayrı responsive düzen.
- Mobil: 750px ve altı.
- `international-register` deposu bu arşivden tamamen ayrıdır ve burada yapılan işlemler onu etkilemez.

## Planlanan sayfa arşivleri

- `homepage/`
- `belgeler/`
- `temsilcilik/`
- `self-defense/`
- `shared/` — ortak footer, responsive yardımcıları vb.

> Not: Hostinger Builder içindeki yerel butonlar, menüler ve SEO paneli ayarları GitHub'a otomatik senkronize olmaz.
